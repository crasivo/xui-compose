🧬 3X-UI Compose
===

Данный репозиторий содержит готовые образы для запуска [3X-UI](https://github.com/MHSanaei/3x-ui) в изолированных контейнерах (
docker/podman).

### Что такое 3X-UI

**3X-UI** — это современная и функциональная веб-панель управления, предназначенная для удобной настройки и администрирования
мощного
ядра Xray. Она позволяет в несколько кликов развернуть полноценный прокси-сервер с поддержкой самых актуальных и защищенных
протоколов, таких как VLESS, VMess, Trojan, Shadowsocks и Hysteria2.

**Основные преимущества:**

1. Универсальность: Поддержка продвинутых механизмов обхода блокировок, включая Reality, XTLS и gRPC.
1. Удобство: Интуитивно понятный веб-интерфейс на нескольких языках с детальной статистикой потребления трафика по каждому
   пользователю.
1. Гибкость: Встроенные инструменты для управления сертификатами SSL, генерации QR-кодов для клиентских подключений и настройки
   правил маршрутизации.
1. Безопасность: Возможность ограничения доступа к панели по IP, смены портов и настройки многопользовательского доступа с
   индивидуальными лимитами.

## 🚀 Быстрый старт

Пример команд для запуска сервиса через [Docker Run](https://docs.docker.com/engine/containers/run/):

```shell
# Root
$ docker run -d --name 3x-ui -p 2053:2053 crasivo/3x-ui
# Rootless
$ docker run -d --name 3x-ui -p 2053:2053 --user xray crasivo/3x-ui
```

После успешного запуска можно перейти в панель управления по адресу http://localhost:2053
Данные для авторизации — `admin:admin`. Тонкие настройки для запуска контейнера описаны ниже.

Ниже представлен пример простого конфигурационного файла `docker-compose.yml` для запуска сервиса через [Docker Compose](https://docs.docker.com/compose/).

```yaml
name: 3x-ui

services:
  3x-ui:
    image: crasivo/3x-ui
    container_name: 3x-ui
    restart: unless-stopped
    environment:
      - "XUI_ADMIN_USERNAME=admin"
      - "XUI_ADMIN_PASSWORD=2UWGn9Ptw6mHmYEPqsvH"
    network_mode: host
    hostname: 3x-ui
```

## 🕹️ Эксплуатация

### Переменные окружения

Образ поддерживает конфигурацию сервиса через переменные окружения.

Сводная таблица доступных переменных окружения:

| Env variable              | Example                                 | Default | Дополнительное описание                                       |
|:--------------------------|:----------------------------------------|:--------|:--------------------------------------------------------------|
| `XUI_ADMIN_USERNAME`      | `admin`                                 | `admin` | Имя пользователя (администратора) Web панели                  |
| `XUI_ADMIN_USERNAME_FILE` | `/run/secrets/xui_admin.name`           | —       | Абсолютный путь до файла, в котором хранится имя пользователя |
| `XUI_ADMIN_PASSWORD`      | `2UWGn9Ptw6mHmYEPqsvH`                  | `admin` | Пароль администратора Web панели                              |
| `XUI_ADMIN_PASSWORD_FILE` | `/run/secrets/xui_admin.pass`           | —       | Абсолютный путь до файла, в котором хранится пароль           |
| `XUI_WEB_BASEPATH`        | `/x-ui/`                                | `/`     | Web путь до панели управления                                 |
| `XUI_WEB_CERT`            | `/usr/local/x-ui/certs/certificate.pem` | —       | Абсолютный путь до публичного SSL сертификата                 |
| `XUI_WEB_CERT_KEY`        | `/usr/local/x-ui/certs/private_key.pem` | —       | Абсолютный путь до приватного ключа SSL сертификата           |

> [!NOTE]
> Полный список поддерживаемых переменных можно посмотреть в
> файле [xui-bootstrap.sh](docker/images/install/bin/xui-bootstrap.sh).
